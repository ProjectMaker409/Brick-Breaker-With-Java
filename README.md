# Brick-Breaker-With-Java
My final project for my AP Comp Sci course styled after the original Break Out (1976) designed by Nolan Bushnell and Steve Bristow and prototyped via discrete logic chips by Steve Wozniak. The game also has additional features to it and is not an emulation.
# Setup
To Run code put All files into one folder as they are currently set up; additionally Ball3 and Ball5 files are used to keep track of players high score, do not edit them.
